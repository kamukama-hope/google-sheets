## 🚀 Quick Start

### Run Website Locally

```bash
# Option 1: Python
cd web
python -m http.server 8000
# Visit: http://localhost:8000

# Option 2: Node.js
cd web
npx http-server
# Visit: http://localhost:8080

# Option 3: VS Code Live Server
# Right-click index.html → "Open with Live Server"
```

### Deploy Website

**Netlify (Recommended):**
1. Connect GitHub repo
2. Set publish directory: `web`
3. Deploy!

**Vercel:**
1. Import project
2. Set root directory: `web`
3. Deploy!

**GitHub Pages:**
1. Copy web/ contents to docs/
2. Push to GitHub
3. Enable Pages in settings
