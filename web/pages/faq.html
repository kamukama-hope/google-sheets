Frequently Asked Questions

Find answers to common questions

General

Is Google Sheets Sorting Helper really free? ▼
Yes, completely free! No hidden costs, no premium features, no ads, and no credit card required. The project is open-source and community-driven. You can even access the source code on GitHub.
How is this project maintained? ▼
The project is maintained by a dedicated team of developers with support from the open-source community. We release regular updates with bug fixes and new features.
What's the difference between Chrome Extension and Workspace Add-on? ▼
Chrome Extension is perfect for individual users with features like keyboard shortcuts and context menus. Workspace Add-on is better for teams and enterprises with admin controls and native integration. You can use both simultaneously!

Installation

How do I install the extension? ▼
Visit our download page, choose your preferred platform (Chrome Web Store or Workspace Marketplace), and click "Install Now". The process takes less than a minute.
Which browsers are supported? ▼
Chrome Extension works on Chrome, Edge, Brave, Firefox, and Safari. Workspace Add-on works in all modern browsers including Safari on iOS (though sorting still requires desktop).
Can I install both Chrome Extension and Workspace Add-on? ▼
Yes! Both can be installed and used together. They complement each other perfectly - use the extension for individual work and the add-on for team collaboration.
Do I need a Google account? ▼
Yes, you need a Google account to use Google Sheets and our tools. Both are free to create and use.

Features & Functionality

How many columns can I sort by? ▼
You can sort by up to 3 columns in a single sort operation (primary, secondary, tertiary). For more complex sorts, you can perform multiple sorts in sequence.
What's the maximum dataset size? ▼
Technically unlimited, but performance degrades with very large datasets. We recommend breaking datasets larger than 100,000 rows into segments for optimal performance.
Can I undo a sort? ▼
Yes! Use Ctrl+Z to undo the last sort. You can also access Google Sheets version history to restore previous states of your spreadsheet.
Does sorting affect formulas? ▼
Formulas move with their rows and are automatically updated. However, be careful with absolute references ($) as they behave differently after sorting.
What happens to merged cells? ▼
Sorting with merged cells can cause issues. We recommend unmerging cells before sorting, then re-merging if needed after the sort.

Data & Security

Is my data safe? ▼
Absolutely! All data processing happens on your device. Your data never leaves Google's infrastructure and is never transmitted to external servers.
Do you track my data? ▼
We have optional analytics that track feature usage and performance metrics, but no personal data is collected. Analytics can be completely disabled in settings.
What permissions does the extension need? ▼
The extension requests only necessary permissions to access Google Sheets and provide sorting functionality. We never request unnecessary permissions.
How is my data backed up? ▼
A backup is automatically created before each sort. Google Sheets also maintains version history so you can restore previous states of your spreadsheet.

Collaboration

Can I sort shared sheets? ▼
Yes, if you have edit access to a shared sheet, you can sort it. Read-only sheets cannot be modified. Make sure other collaborators aren't editing the same range simultaneously.
Can I share sort templates with my team? ▼
Yes! Export your templates and send them to team members. They can import them into their settings. This ensures consistent sorting across your team.
Is there real-time collaboration support? ▼
Not yet, but we're working on real-time collaborative sorting features for v1.2. For now, coordinate with your team before sorting shared sheets.

Support & Help

I'm having issues. Where can I get help? ▼
Check our troubleshooting guide first, then visit our FAQ. If you still need help, contact our support team or open an issue on GitHub.
How do I report a bug? ▼
Visit our GitHub issues page and create a new issue. Include details about what happened, steps to reproduce, and screenshots if helpful.
Can I request a feature? ▼
Absolutely! We value user feedback. Open a discussion on GitHub or contact us directly. The best ideas often come from users like you.
How often are updates released? ▼
We release monthly updates with bug fixes and improvements. Major features are released quarterly. Check our changelog for detailed release notes.

Development

Can I contribute to the project? ▼
Yes! We welcome contributions. Check out our GitHub repository, read the contributing guide, and look for issues labeled "good first issue" to get started.
Is the source code available? ▼
Yes, the complete source code is available on GitHub under the MIT license. You can review it, modify it, and contribute improvements.
How do I set up a development environment? ▼
Clone the repository from GitHub and follow the setup guide in the documentation. You'll need Node.js and npm installed.
