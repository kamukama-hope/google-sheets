Quick Start Guide

Get started with Google Sheets Sorting Helper in just 2 minutes.

Installation (30 seconds)

  • Visit the Chrome Web Store
  • Click "Add to Chrome"
  • Confirm installation
  • Look for the icon in your toolbar

First Sort (1 minute)

  • Open any Google Sheet
  • Select your data (including headers)
  • Click the extension icon
  • Choose a column to sort
  • Click "Sort"

That's it! Your data is now sorted. You can use Ctrl+Z to undo if needed.

Installation

Multiple ways to install based on your preference.

Chrome Extension

Best for individual users. Quick installation from Chrome Web Store.

  • Works on Chrome, Edge, Brave browsers
  • Automatic updates
  • Keyboard shortcuts available
  • Settings page

Workspace Add-on

Best for teams and enterprises. Native integration with Google Workspace.

  • Available to all workspace members
  • Admin controls
  • No toolbar needed
  • Built-in to Google Sheets

You can install both! They work together perfectly.

Your First Sort

Step-by-step guide to complete your first sort.

Step 1: Select Your Data

Open a Google Sheet and select the data you want to sort. Make sure to include the header row.

Step 2: Open the Extension

Click the Sorting Helper icon in your toolbar (or use Ctrl+Shift+S).

Step 3: Choose Your Sort

Select the column to sort and choose ascending or descending order.

Step 4: Apply

Click the "Sort" button. Your data is now sorted!

Tip: Use Preview to see the results before applying.

Basic Sorting

Simple, single-column sorting for everyday use.

How to Basic Sort

  • Select data range
  • Click extension icon
  • Choose column
  • Choose A-Z or Z-A
  • Click Sort

Data Types

The extension automatically detects your data type:

  • Text: Sorted alphabetically (A-Z)
  • Numbers: Sorted numerically
  • Dates: Sorted chronologically
  • Mixed: Intelligently sorted

Keyboard Shortcut

Ctrl+Shift+S

Advanced Sorting

Sort by multiple columns with different priorities.

Multi-Column Sort

Sort by up to 3 columns simultaneously.

Example: Employee Data

  • Primary: Department (A-Z)
  • Secondary: Salary (High to Low)
  • Tertiary: Last Name (A-Z)

This results in: Employees grouped by department, highest earners first within each department, alphabetically by last name.

Keyboard Shortcut

Ctrl+Shift+A

Smart Sort

Let AI analyze your data and recommend optimal sorting.

How Smart Sort Works

  • Analyzes data types and patterns
  • Evaluates data completeness
  • Suggests logical sort order
  • Provides confidence score

Using Smart Sort

  • Select your data
  • Press Ctrl+Shift+I
  • Review recommendations
  • Accept or modify
  • Apply sort

Tip: Smart Sort is great for exploring new datasets!

Custom Sort Orders

Sort by non-alphabetical sequences.

When to Use

  • Months (Jan, Feb, Mar...)
  • Sizes (XS, S, M, L, XL)
  • Priorities (High, Medium, Low)
  • Status (Planned, In Progress, Complete)

Create Custom Order

  • Right-click extension → Options
  • Go to "Sorting" tab
  • Click "Add Custom Order"
  • Name your order
  • Define the sequence
  • Save

Save Templates

Save and reuse your sort configurations.

Why Use Templates?

  • Quick reuse of complex sorts
  • Share with team members
  • Maintain consistency
  • Save setup time

Save a Template

  • Configure your sort
  • Click "Save as Template"
  • Name your template
  • Save

Use a Template

  • Open sort dialog
  • Click "Load Template"
  • Select your template
  • Apply

Live Preview

See exactly how your data will look before applying changes.

Preview Workflow

  • Configure your sort
  • Click "Preview"
  • Review sample data
  • Choose: Apply or Cancel

Recommendation: Always use preview with important data!

Keyboard Shortcuts

Speed up your workflow with keyboard shortcuts.

Available Shortcuts

Ctrl+Shift+S - Open Quick Sort Ctrl+Shift+A - Open Advanced Sort Ctrl+Shift+I - Open Smart Sort Ctrl+Shift+E - Open Popup Ctrl+Z - Undo last sort

Customize Shortcuts

Go to Options → Shortcuts tab to customize keyboard shortcuts to your preference.
