## 🎯 Common Use Cases

### New User
1. Read [Quick Start](docs/QUICKSTART.md) (2 min)
2. Try first sort
3. Explore [User Guide](docs/USER_GUIDE.md) (30 min)
4. Customize in Options page
5. Save templates for your workflow

### User with Problem
1. Check [Troubleshooting FAQ](docs/TROUBLESHOOTING.md#faq)
2. Look for specific issue section
3. Follow troubleshooting steps
4. If not solved, [report issue](https://github.com/kiro-sheets-helper/issues)

### Developer Starting Out
1. Read [Setup Guide](docs/SETUP.md)
2. Clone and install dependencies
3. Review [Architecture](ARCHITECTURE.md)
4. Check [API Reference](docs/API-INTEGRATION.md)
5. Start with [Contributing Guide](CONTRIBUTING.md)

### First-Time Contributor
1. Read [Contributing Guide](CONTRIBUTING.md)
2. Look for "good first issue" on GitHub
3. Review code [style guide](CONTRIBUTING.md#code-style)
4. Read [Testing Guide](docs/TESTING.md)
5. Submit pull request

### Release Manager
1. Check [Release Checklist](docs/RELEASE.md)
2. Follow [Release Process](docs/RELEASE.md#release-process)
3. Update [Changelog](CHANGELOG.md)
4. Use [Deployment Guide](docs/DEPLOYMENT.md)
5. Monitor post-release [feedback](https://github.com/kiro-sheets-helper/issues)
