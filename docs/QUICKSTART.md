# Quick Start Guide

Get up and running with Google Sheets Sorting Helper in 2 minutes.

## Installation (Choose One)

### Option 1: Chrome Extension (Recommended)
```
1. Open Chrome → Chrome Web Store
2. Search "Google Sheets Sorting Helper"
3. Click "Add to Chrome" → "Add extension"
4. Icon appears in toolbar ✓
```

### Option 2: Google Workspace Add-on
```
1. Open any Google Sheet
2. Extensions → Add-ons → Get add-ons
3. Search "Google Sheets Sorting Helper"
4. Click → Install → Grant permissions ✓
```

## First Sort (30 seconds)

```
1. Open Google Sheets
2. Create sample data or paste this:
   Name,Salary,Department
   Alice,95000,Engineering
   Bob,75000,Sales
   Charlie,85000,Marketing

3. Select all data (A1:C4)
4. Click extension icon (Chrome) OR
   Extensions → Add-on name (Workspace)
5. Choose column "Salary" → "Descending"
6. Click Sort → Done! ✓
```

## Common Tasks

### Sort by Multiple Columns
```
1. Select data
2. Press Ctrl+Shift+A
3. Add criteria:
   - Primary: Department
   - Secondary: Salary (Descending)
4. Click Apply
```

### Create Custom Sort Order
```
1. Right-click extension → Options
2. Sorting tab → Add Custom Order
3. Name: "Month Order"
4. Values: Jan, Feb, Mar, Apr...
5. Save → Use in sorts
```

### Save Sort Template
```
1. Configure your sort
2. Click "Save as Template"
3. Name: "Employee Sort"
4. Next time: Load Template → Apply
```

### Preview Before Sorting
```
1. Set up sort criteria
2. Click Preview button
3. Review sample of results
4. Click Apply to confirm
```

## Tips

✅ **Always select data including headers**  
✅ **Use Preview to avoid mistakes**  
✅ **Save templates for repeated sorts**  
✅ **Enable auto-detect headers in settings**  

⚠️ **Avoid sorting with merged cells**  
⚠️ **Don't interrupt mid-sort**  
⚠️ **Test on small dataset first**
